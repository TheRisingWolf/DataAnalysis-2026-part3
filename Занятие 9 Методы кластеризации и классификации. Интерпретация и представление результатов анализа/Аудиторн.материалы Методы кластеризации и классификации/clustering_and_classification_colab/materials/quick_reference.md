# Краткая памятка

## Кластеризация

**Вопрос:** как автоматически найти группы похожих объектов, если правильные классы заранее неизвестны?

**K-Means:** разделяет объекты на `k` групп так, чтобы объекты внутри группы были ближе друг к другу.

Перед K-Means для признаков разных масштабов используйте `StandardScaler`.

Проверяйте:

- inertia — внутрикластерный разброс;
- silhouette score — насколько объекты похожи на свой кластер и отличаются от соседнего;
- содержательность профилей — имеют ли найденные группы практический смысл.

Номер кластера `0`, `1`, `2` — только техническая метка.

## Классификация

**Вопрос:** как по признакам предсказать заранее известный класс объекта?

В нашем кейсе target — `sla_breached`.

Обязательная последовательность:

`выбрать доступные признаки → train/test split → preprocessing на train → baseline → модель → прогноз test → метрики`

## Метрики

- **Accuracy** — доля всех правильных ответов.
- **Precision** — среди объектов, которым модель поставила класс 1, какая доля действительно относится к классу 1.
- **Recall** — среди всех реальных объектов класса 1, какую долю модель нашла.
- **F1** — баланс precision и recall.
- **Confusion matrix** — таблица типов правильных и ошибочных ответов.

## Важные ошибки

- не масштабировать признаки перед K-Means;
- считать кластеры «правильными классами»;
- выбирать `k` только потому, что «так красиво»;
- использовать информацию будущего при прогнозировании;
- обучать preprocessing на полном датасете до train/test split;
- оценивать модель только на train;
- смотреть только на accuracy;
- считать feature importance доказательством причинности.
