# Кластеризация и классификация данных — комплект для Google Colab

Комплект адаптирован для проведения 90-минутного практического занятия в **Google Colab**.

## Что открыть

- Слушателю: `notebooks/student_practice_colab.ipynb`
- Преподавателю: `notebooks/teacher_solution_colab.ipynb`
- Исходный датасет: `data/raw/support_tickets.csv`

## Быстрый запуск в Google Colab

1. Откройте нужный `.ipynb` в Google Colab.
2. Запускайте ячейки сверху вниз.
3. В начале notebook автоматически проверит наличие `support_tickets.csv`.
4. Если CSV отсутствует в среде Colab, появится окно загрузки файла.
5. Выберите `data/raw/support_tickets.csv` из этого комплекта.
6. Продолжайте выполнение notebook.

Никакие абсолютные пути пользователя указывать не требуется.

## Где сохраняются результаты

В Google Colab результаты создаются в:

```text
/content/clustering_and_classification_outputs/
├── charts/
├── support_tickets_with_clusters.csv
├── cluster_profile.csv
├── classification_metrics.csv
└── classification_predictions.csv
```

В конце notebook есть **опциональная** ячейка, которая может упаковать результаты в ZIP и скачать их через браузер. Она отключена по умолчанию, чтобы `Run all` выполнялся без неожиданных скачиваний.

## Библиотеки

Используются стандартные для Colab библиотеки:

- pandas;
- numpy;
- matplotlib;
- scikit-learn.

Notebook печатает версии Python, pandas и numpy в начале работы. Если среда Colab была изменена вручную или пакет удалён, перезапустите среду выполнения или установите пакет заново.

## Локальный запуск

Эти Colab-notebooks также можно запускать в обычном Jupyter. В локальном режиме они автоматически ищут:

```text
data/raw/support_tickets.csv
```

и сохраняют результаты в локальную папку `outputs/`.

## Логика практики

Материал идёт от простого к сложному:

1. проверка данных;
2. визуальный поиск групп;
3. K-Means на двух признаках;
4. масштабирование;
5. кластеризация по нескольким признакам;
6. выбор числа кластеров;
7. профилирование кластеров;
8. постановка задачи классификации;
9. предотвращение target leakage;
10. baseline;
11. Logistic Regression;
12. Decision Tree;
13. сравнение accuracy, precision, recall и F1;
14. confusion matrix;
15. сохранение результатов и аналитический вывод.

Весь учебный код содержит комментарии на русском языке.

## Контрольные результаты

В полном преподавательском комплекте каталог `reference_outputs/` содержит результат контрольного запуска. Он нужен для быстрой сверки преподавателем и не используется notebook как источник данных.
