# Кластеризация и классификация данных: от поиска групп к прогнозу

## Назначение

Практический комплект предназначен для 90-минутного занятия по аналитике данных. На одном кейсе службы поддержки слушатели проходят путь от поиска естественных групп обращений до прогноза риска нарушения SLA.

Основная логика занятия:

`данные → признаки → кластеризация → профилирование → целевая переменная → классификация → метрики → аналитический вывод`

## Быстрый старт локально

1. Распакуйте комплект в отдельную папку.
2. Откройте терминал в корне проекта.
3. При необходимости создайте виртуальное окружение.
4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Запустите Jupyter:

```bash
jupyter notebook
```

6. Для слушателя откройте `notebooks/student_practice.ipynb`.
7. Для преподавателя откройте `notebooks/teacher_solution.ipynb`.
8. Выполняйте notebook сверху вниз.

## Google Colab

Notebook не использует абсолютные пути. Если вы работаете в Google Colab, можно загрузить notebook и `support_tickets.csv` в текущую рабочую область. Проверочный блок автоматически ищет данные как в структуре проекта `data/raw/`, так и рядом с notebook.

После перезапуска среды Colab нужно повторно выполнить ячейки сверху вниз и при необходимости заново загрузить CSV.

## Ожидаемые контрольные результаты

При исходном `random_state=42`:

- строк в исходном датасете: `2500`;
- пропусков: `0`;
- дубликатов `ticket_id`: `0`;
- доля класса `sla_breached = 1`: около `0.30`;
- для учебных данных наиболее выраженная структура обычно получается при `k = 3`;
- baseline по accuracy заметно уступает обученным классификаторам;
- Logistic Regression и Decision Tree должны давать существенно более высокий recall класса нарушения SLA, чем baseline.

Точные метрики могут незначительно различаться между версиями библиотек, но общая аналитическая картина должна сохраняться.

## Что сохраняется после выполнения

- `cluster_profile.csv`;
- `classification_metrics.csv`;
- `classification_predictions.csv`;
- графики в `outputs/charts/`.

## Типовые проблемы

**Файл не найден.** Проверьте, что `support_tickets.csv` лежит в `data/raw/` или рядом с notebook в Colab.

**Не установлен scikit-learn.** Выполните `pip install -r requirements.txt` либо используйте Google Colab.

**Результаты отличаются.** Проверьте, что не изменены `random_state=42`, признаки и параметры моделей.

**После изменения ячейки результат выглядит странно.** Перезапустите ядро и выполните notebook сверху вниз.

## Учебный акцент

Этот комплект не ставит целью подготовку ML-инженера. Основной результат для аналитика данных — уметь правильно поставить задачу, подготовить признаки, применить метод, проверить качество и перевести результат модели в содержательный аналитический вывод.
