# Метаданные синтетического датасета продаж электроники

## Назначение

Датасет создан для учебного примера итоговой аналитической работы. Он поддерживает ETL, preprocessing, EDA, статистические проверки, ABC-XYZ, RFM и подготовку витрин для Yandex DataLens.

Данные полностью синтетические и не описывают реальный бизнес.

## Технические характеристики

- Исходный файл: `data/raw/electronics_sales_10000.csv`
- Формат: CSV
- Кодировка: UTF-8 with BOM
- Разделитель: запятая
- Размер исходного файла: **10 000 строк, 18 столбцов**
- Период: 01.01.2025–31.12.2025
- Единица наблюдения: одна товарная позиция (line item) в заказе
- Уникальный ключ после удаления полных дублей: `line_id`
- Заказ идентифицируется полем `order_id`; один заказ может содержать несколько строк

## Словарь полей

| Поле | Смысл |
|---|---|
| `line_id` | уникальный идентификатор строки продажи |
| `order_id` | идентификатор заказа |
| `sale_date` | дата продажи |
| `customer_id` | синтетический идентификатор покупателя |
| `customer_segment` | исходный учебный сегмент клиента |
| `city` | город продажи/доставки |
| `sales_channel` | Магазин / Сайт / Маркетплейс |
| `category` | товарная категория |
| `brand` | бренд |
| `product_id` | идентификатор товара |
| `product_name` | учебное название товара |
| `quantity` | количество единиц в строке |
| `unit_price_rub` | цена одной единицы до скидки |
| `discount_pct` | доля скидки от 0 до 1 |
| `unit_cost_rub` | учебная себестоимость одной единицы |
| `payment_method` | способ оплаты |
| `promo_campaign` | акция/кампания |
| `returned` | признак возврата: 1 — возвращено, 0 — нет |

## Намеренно добавленные учебные дефекты

В исходный файл контролируемо включены:

- 25 полных дублей;
- смешанные форматы даты;
- пробелы и различия регистра в категориальных значениях;
- пропуски в `customer_segment`, `discount_pct`, `unit_cost_rub`, `payment_method`;
- некорректные значения количества;
- отрицательные и аномально большие цены;
- скидки вне допустимого диапазона;
- отрицательные и аномально большие значения себестоимости.

## Правила очистки

- полные дубликаты удаляются;
- даты приводятся к `datetime`;
- текстовые категории нормализуются;
- пропуски восстанавливаются только там, где это обосновано учебным правилом;
- некорректные числовые значения заменяются устойчивыми групповыми медианами;
- исходный файл не перезаписывается;
- после очистки выполняются assert-проверки диапазонов, ключей и пропусков.

## Производные показатели

Notebook рассчитывает:

- `gross_revenue_rub` — сумма до скидки;
- `discount_amount_rub` — сумма скидки;
- `sales_after_discount_rub` — продажа после скидки;
- `net_revenue_rub` — выручка после учёта возврата в упрощённой учебной модели;
- `cost_total_rub` — себестоимость реализованных единиц после учёта возврата;
- `gross_profit_rub` — валовая прибыль;
- `margin_pct` — маржинальность строки;
- календарные поля для BI.

## Ограничения модели

- возврат упрощённо обнуляет выручку и себестоимость строки, без моделирования логистики возврата и частичных возвратов;
- налоговый учёт, НДС, бонусы, доставка, комиссии маркетплейсов и операционные расходы не моделируются;
- стоимость и себестоимость синтетические;
- статистические зависимости специально заложены для обучения и не переносятся на реальный ритейл;
- ABC-XYZ и RFM используют учебные правила сегментации, которые в реальном бизнесе должны согласовываться с владельцем методологии.
