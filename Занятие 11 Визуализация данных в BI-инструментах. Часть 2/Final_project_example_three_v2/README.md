# Учебный пример итоговой работы: продажи магазина электроники

Этот комплект реализует **только пункт 1.2 итогового задания**: подготовку данных, ETL, preprocessing и исследовательский анализ данных (EDA) на синтетическом кейсе магазина электроники.

## Граница комплекта

В комплекте **не выполняется пункт 2.1**: дашборды, чарты, Story, публикация и настройка аналитического приложения в Yandex DataLens должны выполняться отдельно на следующем этапе.

Также в текущую версию не включены ABC-XYZ и RFM из пункта 2.2. Сначала формируется корректный результат задания 1.2 — очищенные и аналитически подготовленные данные.

## Что выполняется в задании 1.2

1. Формулируются цель анализа, аналитические вопросы и рабочие гипотезы.
2. Подготавливается окружение и загружается исходный CSV.
3. Выполняется первичный осмотр данных: размер, поля, типы, описательные статистики и уникальные значения.
4. Проверяются даты, пропуски, полные дубликаты, уникальность идентификаторов, категории и числовые аномалии.
5. Выполняется очистка/ETL с повторным контролем качества.
6. Выполняется preprocessing и создаются производные аналитические признаки.
7. Проводится EDA: KPI, распределения, временная динамика, категории, каналы, товары, возвраты, скидки и корреляции.
8. Дополнительно проверяются три рабочие статистические гипотезы.
9. Сохраняются очищенные данные и готовится итоговая сводка.

## С чего начать

1. Установите зависимости из `requirements_electronics_analysis.txt`.
2. Для самостоятельной работы откройте `electronics_store_sales_analysis_starter.ipynb`.
3. Для изучения эталонного решения откройте `electronics_store_sales_analysis_final.ipynb`.
4. Исходный набор находится в `data/raw/electronics_sales_10000.csv` и содержит ровно **10 000 строк**.
5. После выполнения решения формируются два CSV в `data/processed/` и графики EDA в `outputs/eda_charts/`.

## Какой файл использовать далее в пункте 2.1

Основным входом для последующего построения BI-дашборда является:

```text
data/processed/electronics_sales_analysis_ready.csv
```

Он содержит очищенные данные на уровне товарной позиции заказа и производные показатели, необходимые для дальнейшего проектирования KPI и визуализаций.

**Само выполнение пункта 2.1 в этот комплект не входит.**

## Важно

Все данные полностью синтетические. Они не описывают реальный магазин, покупателей, цены, бренды, акции или коммерческие результаты.
