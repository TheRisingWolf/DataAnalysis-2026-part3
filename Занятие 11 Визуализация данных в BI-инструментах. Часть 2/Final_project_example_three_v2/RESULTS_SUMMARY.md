# Результаты задания 1.2: аналитика продаж магазина электроники

## Итоговые наблюдения по синтетическим данным

- Исходный набор: **10,000 строк**.
- После очистки: **9,975 строк** и **6,000 уникальных заказов**.
- Чистая выручка учебной выборки: **510,820,817 руб.**
- Валовая прибыль: **119,397,206 руб.**
- Средний чек: **85,137 руб.**
- Общая маржинальность: **23.4%**.
- Лидер по выручке среди категорий: **Ноутбуки**.
- Лидер по выручке среди каналов: **Магазин**.
- Наибольшая доля возвратов наблюдается у категории **Игровая техника** (9.2%).

## Статистические проверки рабочих гипотез

- H1: p-value = **8.61e-17**, rank-biserial = **0.096** (малый эффект).
- H2: p-value = **2.94e-10**, Cramer's V = **0.075** (малый эффект).
- H3: rho = **0.082**, p-value = **2.05e-16** (очень слабый по силе).

Статистическая значимость не означает причинность; результаты относятся только к синтетической учебной выборке.
